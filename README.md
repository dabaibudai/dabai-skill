# dabai-skill

Dabai 的 Agent Skill 库。

## 当前技能

- [`agents-md-doctor`](./agents-md-doctor/)：基于文本证据审计和改进 `AGENTS.md` 指令系统，覆盖索引、继承、冲突、重复、可执行性与安全边界。

## 使用

将需要的技能目录复制到 Agent 的 skills 目录，并保留其中的 `SKILL.md`、`references/` 与 `scripts/`。

## 贡献

新增或更新 Skill 前，请先阅读 [`CONTRIBUTING.md`](./CONTRIBUTING.md) 中的上传规范。
